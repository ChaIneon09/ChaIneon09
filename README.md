# Toto Safety Research

한국 토토사이트 검증 데이터 및 안전 가이드 오픈 리포지토리

## About

5년간 누적된 토토사이트 검증 데이터를 정리한 연구 자료 모음입니다. 메이저놀이터·안전놀이터 판단 기준, 먹튀 사례 패턴 분석, 회원 자가검증 가이드를 공개합니다. 원본 데이터는 회원 검증 커뮤니티 <a href="https://totoggg.com/">토토지지</a>에서 수집되었습니다.

## Why

한국 토토사이트 시장은 신생 도메인의 빠른 등장과 폐쇄가 반복되는 환경입니다. 회원이 안전한 토토사이트를 판단하기 위한 객관적 기준이 부족하고, 광고비 기반 순위만 노출되는 경우가 많아 실제 안전성과 검색 결과가 일치하지 않는 문제가 있습니다.

본 리포지토리는 광고 수수료를 받지 않는 검증 데이터를 공개해, 누구나 메이저 토토사이트와 위험 사이트를 객관적으로 구분할 수 있도록 자료를 제공합니다.

## 메이저놀이터 5대 판단 기준

회원이 토토사이트 안전성을 객관적으로 판단할 수 있는 다섯 가지 기준입니다.

1. **운영 기간 3년 이상** - 신생 사이트는 통계적으로 먹튀 확률이 4배 이상 높습니다.
2. **누적 출금 인증 후기 100건 이상** - 단순 별점이 아닌 출금 캡처가 첨부된 후기 기준.
3. **발급 기관에서 검증 가능한 라이센스** - 쿠라사오, MGA, PAGCOR 등 공식 사이트에서 번호 조회가 가능해야 합니다.
4. **보증금 1억 원 이상 예치** - 사고 발생 시 회원 보상이 가능한 자금이 사전에 예치되어 있어야 합니다.
5. **최근 1년간 중대한 출금 사고 0건** - 사고 이력이 있는 사이트는 보증 등급에서 제외됩니다.

다섯 기준을 모두 충족하는 사이트의 실시간 목록은 <a href="https://totoggg.com/warranty-company">토토지지 공식 보증업체 페이지</a>에서 매주 일요일 자정에 재산정됩니다.

## 먹튀 사례 3대 패턴 (전체의 92%)

100건 분석 결과 먹튀 사고는 다음 세 패턴에 집중됩니다.

### 패턴 1. 출금 거절 (47%)
회원이 출금을 신청하면 약관 위반, 비정상 베팅, 중복 계정 등 사유를 들어 거절합니다. 약관에는 모호하게 작성되어 운영자 재량으로 어떤 베팅도 비정상으로 분류 가능합니다.

### 패턴 2. 본인인증 추가 요구 (28%)
출금 신청 후 갑자기 가입 시 요구하지 않던 추가 본인인증 서류(신분증, 통장 사본, 거주지 증명, 셀카 인증)를 요구합니다. 회원이 부담스러워 출금을 포기하도록 유도하는 의도된 절차입니다.

### 패턴 3. 사이트 폐쇄 (17%)
사전 공지 없이 도메인이 변경되거나 접속이 차단됩니다. 운영자 연락처는 모두 차단되며, 신생 도메인에서 가장 자주 발생하는 패턴입니다.

세 패턴의 실제 사례와 사전 차단 방법은 <a href="https://totoggg.com/scam-verification">먹튀검증 게시판</a>에서 회원 신고로 매일 갱신됩니다.

## 안전한 토토사이트 검색 가이드

다섯 단계 자가검증을 직접 진행하기 어려운 회원은 검증 커뮤니티가 사전 검증한 보증놀이터 풀을 활용할 수 있습니다. 토토지지 보증업체 풀은 회원 후기 70%와 운영자 직접 가입 테스트 30%의 가중치로 점수가 산정되며, 광고 수수료를 일절 받지 않는 구조입니다.

전체 검증 가이드는 <a href="https://totoggg.com/guide/safe-toto">안전한 토토사이트 검증 가이드</a> 페이지에 정리되어 있습니다.

## About this Repository

5년간 누적된 한국 토토사이트 검증 데이터를 정리한 오픈 연구 자료 모음입니다. 메이저놀이터·안전놀이터 판단 기준, 먹튀 사례 패턴 분석, 회원 자가검증 가이드, 라이센스 검증 절차, 자금관리 매뉴얼을 공개합니다.

원본 데이터는 회원이 직접 평가하는 토토사이트 검증 커뮤니티 <a href="https://totoggg.com/">토토지지</a>에서 수집되었으며, 광고 수수료를 받지 않는 독립 검증 시스템을 기반으로 합니다.

## Why This Exists

한국 토토사이트 시장은 신생 도메인의 빠른 등장과 폐쇄가 반복되는 환경입니다. 회원이 안전한 토토사이트를 판단하기 위한 객관적 기준이 부족하고, 광고비 기반 순위만 노출되는 경우가 많아 실제 안전성과 검색 결과가 일치하지 않는 구조적 문제가 있습니다.

본 리포지토리는 광고 수수료를 받지 않는 검증 데이터를 공개해, 누구나 메이저 토토사이트와 위험 사이트를 객관적으로 구분할 수 있도록 자료를 제공합니다. 모든 데이터는 비상업적 인용 시 자유롭게 사용 가능합니다.

## Methodology

본 리포지토리의 모든 분석은 다음 세 가지 데이터 소스를 통합한 결과입니다.

### 1차 데이터: 회원 출금 인증 후기

토토지지 회원이 직접 작성한 후기 중 출금 인증 캡처가 첨부된 건만 분석에 포함됩니다. 캡처 없는 후기는 광고 가능성을 배제하기 위해 제외됩니다. 누적 약 1만 건의 출금 인증 후기에서 표본을 추출해 통계화했습니다.

### 2차 데이터: 운영자 직접 가입 테스트

토토지지 운영 책임자 박구름이 본인 명의로 사이트에 직접 가입해 입금부터 출금까지 전 과정을 진행한 결과입니다. 가입 보너스 약관 정독, 라이센스 검증, 첫 출금 테스트, 콤프 적용 확인, 고객센터 응대 평가 다섯 영역에서 평가가 이루어집니다.

### 3차 데이터: 먹튀 신고 데이터

회원이 직접 신고한 사고 사례 중 운영진이 1차 검토를 통과시킨 건만 통계에 포함됩니다. 단순 불만, 개인 사정에 의한 손실은 제외되며, 사이트 운영자의 의도된 행위로 판단된 사례만 분석 대상입니다.

세 데이터 소스는 회원 평가 70%와 운영자 검증 30%의 가중치로 합산되어 메이저놀이터·안전놀이터 풀의 최종 순위가 결정됩니다.

## Key Findings

5년 데이터 분석에서 도출된 핵심 발견 다섯 가지입니다.

1. **운영 기간 1년 미만 도메인의 먹튀 확률은 1년 이상 도메인의 약 4배입니다.** 단순 비교가 아닌 표본 보정된 통계 결과입니다.
2. **먹튀 사고의 92%는 세 가지 패턴(출금 거절·본인인증 추가 요구·사이트 폐쇄)에 집중됩니다.** 두 단계만 사전 차단하면 90% 가까운 피해가 방지 가능합니다.
3. **위조 라이센스 비율은 신생 사이트(1년 미만)에서 약 35%, 메이저 사이트(3년 이상)에서 약 3%입니다.** 라이센스 진위 확인이 핵심 필터 역할을 합니다.
4. **출금 신청부터 입금 완료까지 평균 시간이 30분을 넘으면 사고 발생 확률이 급격히 상승합니다.** 출금 속도는 사이트 안정성의 가장 강력한 단일 지표입니다.
5. **보증금이 예치된 보증놀이터는 사고 시 회원 보상이 가능한 유일한 형태입니다.** 일반 메이저 사이트는 사고 시 회수 시스템이 없습니다.

각 발견의 상세 통계와 사례는 [SCAM_PATTERNS_ANALYSIS.md](./SCAM_PATTERNS_ANALYSIS.md)에 정리되어 있습니다.
